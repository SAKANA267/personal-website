# personal_website（Vue 全栈重写版）

这是对原项目 `nihonggo_web_learning`（开发者 SAKANA 的个人网站）的**忠实移植**：在不修改信息与功能的前提下，把技术栈从「原生 HTML/CSS/JS + PHP/MySQL + Node WebSocket」重写为「Vue 3 + TypeScript SPA + Node/Express + MySQL + ws」。所有文案、视觉、动画与交互行为均原样保留。

>该站点是 SAKANA 的个人网站（首页 / 在线聊天 / 自定义题库 / 开发日志 / 博客 / 二维码分享 / 登录注册）

## 目录结构

```
personal_website/
├─ package.json          # workspaces 根，concurrently 同时启动前后端
├─ client/               # Vue 3 + TS + Vite + Vue Router（SPA）
├─ server/               # Node + Express + mysql2 + ws（TypeScript，tsx 运行）
└─ deploy/               # 部署脚本 + PM2 配置 + nginx 样例（详见 deploy/README.md）
```

## 准备

1. 安装依赖（根目录会同时安装两个 workspace）：
   ```bash
   npm install
   ```
2. 创建数据库并导入表结构（依据 `server/src/schema.sql`）。
3. 配置环境变量：
   - 复制 `server/.env.example` → `server/.env`，填入数据库连接、端口、SESSION_SECRET（生产缺失将拒绝启动）、ADMIN_USERNAMES（管理员白名单）、SHARE_MAX_MB（分享上传上限）、BLOG_IMAGE_MAX_MB（博客插图上限，默认 8）、AVATAR_MAX_MB（头像上传上限，默认 2）、BANNER_MAX_MB（主页壁纸上限，默认 4）、ALTCHA_HMAC_KEY（登录页人机验证的挑战签名密钥，缺省自动改用进程级随机密钥）。
   - 复制 `client/.env.example` → `client/.env`（dev 默认即可）。

## 开发

```bash
npm run dev
```

- 前端：http://localhost:5173/web/ （Vite，`base: '/web/'`，`/api` 代理到后端 3000）
- 后端：http://localhost:3000 （Express）
- 聊天 WebSocket：ws://localhost:9000

## 生产构建

```bash
npm run build        # 产出 client/dist
npm start            # 启动 server
```

生产环境将 `client/.env.production` 的 `VITE_WS_URL` 指向 `wss://...`，并在 `server/.env` 中开启 `WS_USE_SSL=true` 并提供证书路径。站点挂在 nginx 子路径 `/web/` 下（nginx 剥除前缀后反代 Node，完整样例见 `deploy/nginx.conf.example`）。

## 登录/注册人机验证（ALTCHA）

登录页与注册页均集成开源 PoW 验证码 [ALTCHA](https://altcha.org)（无第三方追踪、无图片识别，浏览器用算力解题）：

- **体验**：勾选「我不是机器人」→ 浏览器自动解题（约半秒，内置 Web Worker）→ 绿色对勾即可提交；语言随站点 zh/en 切换。提交失败（口令错/验证过期/用户名已存在）会自动重置，重解一次即可。
- **服务端**（`server/src/altcha.ts` + `routes/auth.ts`，登录与注册共用同一套出题/核销）：`GET /api/auth/altcha-challenge` 出题（PBKDF2/SHA-256，120 秒有效，带 HMAC 签名），登录/注册请求须附 `altcha` 解字段；验证为**一次性**（nonce 核销防重放），错误码 `AUTH_CAPTCHA_REQUIRED / INVALID / EXPIRED`。防刷叠加在原有按 IP 限流之上（登录 20 次/5 分钟、注册 10 次/小时），脚本每次尝试都要实付约 128 万次哈希迭代的算力。
- **兼容性**：CSP 因此新增 `worker-src 'self' blob:`（ALTCHA 以 blob URL 构造 PoW worker，无此指令生产环境解题必被拦截）；altcha 包无 engines 限制、唯一依赖 hash-wasm（纯 WASM），线上 Node 18 可用（库依赖的 WebCrypto 全局 Node 18 起自带，代码内另有兜底赋值）。

## 白天/黑夜模式

顶部导航条右侧的日/月图标按钮一键切换全站配色（纸墨反转：亮色纸底墨字 ↔ 暗色墨底纸字），零依赖手写实现（约百行 store + CSS 变量覆盖，不引第三方库）：

- **规则**：首次访问跟随系统 `prefers-color-scheme`；手动切换后以 `localStorage['theme']` 的显式选择为准（不再跟随系统）。`index.html` 内联脚本在首帧前挂类，重载无亮色闪烁；移动端浏览器地址栏底色（theme-color）随主题联动。
- **实现**：切换即给 `<html>` 挂/摘 `dark` 类，`design-system.css` 的 `html.dark` 覆盖 `--ink`/`--paper`/灰阶变量，全站经既有变量间接层整体翻转（含表单、代码块、ALTCHA 验证组件）；过渡为 200ms 色彩渐变，`prefers-reduced-motion` 用户瞬时切换。图表实验室页有独立暖纸色板，单独换板。
- **刻意不随主题**：标题卡封面（本就是深色）、管理面板（独立亮色墨纸体系，导航条幽灵态钉回亮色图标）、二维码结果白底（保证扫码）、题库代码高亮（本就是 VS Code 深色）。

## 博客撰写

登录后 `/blog/compose`（写文章）支持两项工具增强：

- **插入图片**：上传 PNG / JPG / GIF / WebP / BMP / AVIF（单张 ≤ 8MB，`BLOG_IMAGE_MAX_MB` 可调），上传面板可填写「图片说明」；插入后在正文中生成 `![说明](图片地址)`，文章里渲染为图片 + 图片下方居中说明。上传时服务端自动生成 **WebP 压缩展示版**（宽 ≤1600、质量 82，动图保留动画；小图不压缩），文章默认读压缩版，图片下方徽标标注当前读取的大小并提供「查看原图（原图大小）」链接（新标签页打开原图），原图永久保留。安全侧做 mime 白名单 + 扩展名一致性 + 魔数嗅探三重校验（伪装成图片的 HTML/脚本一律拒绝），SVG 因可携带脚本始终拒绝，并按用户限流与限额。
- **导入 .md 文件**：不想用网页编辑器的作者可在本地写好 `.md`（支持 frontmatter 的 title / category / tags）后一键导入，自动填充表单；文件只在浏览器本地读取，不经服务器。

取消上传/改稿残留的未引用图片由管理面板「博客文章 → 清理未引用图片」一键回收。

## 个人主页

每个登录用户都有一个公开主页 `/u/用户名`（`/u/me` 指向自己，未登录时引导登录；旧地址 `/account` 自动重定向至此）：

- **资料展示**：头像（无头像时用昵称首字占位）、昵称、用户名、注册时间、简介、地区、社交链接，以及文章 / 评论 / 获赞三个统计数字。他人与游客只能看到公开信息——字段裁剪在服务端按隐私设置完成。
- **编辑资料**：昵称 / 简介 / 地区 / 社交链接（≤5 条，地址须以 http(s):// 开头）在线编辑，保存后主页立即更新，取消则恢复原内容。
- **头像与壁纸管理**：选图后进入**裁剪**（拖动调整位置，滚轮 / 双指 / 按钮缩放，可重置；头像 1:1、壁纸 4:1 所见即所得）再上传——服务端头像重编码为 256×256 WebP、壁纸等比压到 ≤1600×400 WebP（原始选图 ≤2MB / ≤4MB，动图裁剪后为静帧）；悬停头像/壁纸可更换，头像可删除恢复默认首字，壁纸为头卡顶部横幅条带（占正文列宽 × 约 150px，移动端收窄，**不是全屏背景**）、头像叠在壁纸下缘（GitHub 风），无壁纸时本人视角显示「添加主页壁纸」虚线占位条、他人视角不渲染。
- **我的内容**：文章标签（本人含草稿，可编辑/删除）与评论标签，分页加载；博客列表与阅读页的作者名、评论者名均链到对应主页。
- **隐私设置**：主页是否公开、地区 / 社交链接 / 文章评论是否对外展示、是否允许搜索引擎收录（关闭时页面挂 `noindex`），保存即生效。私密主页仅本人与管理员可见，他人看到锁定提示。
- **账号安全**：修改密码（验旧密码）、退出登录；管理员额外保留「重置用户密码」工具。注销账号需密码验证 + 输入用户名二次确认，后果如实告知（文章/评论/点赞/插图/分享全部删除，留言板与聊天日志保留，账号行匿名化、无法再登录）。
- **管理员治理**：管理面板用户 tab 可禁用/启用账号（白名单管理员不可被禁用）；被禁用账号无法登录，主页显示「已被停用」，已注销账号主页显示「已注销」。

部署本次升级需按 `server/src/schema.sql` 迁移注释为 `users` 表补 13 个列（资料 / 隐私 / 状态 / 注册时间）；头像上限可用 `AVATAR_MAX_MB` 调整（默认 2MB，需 ≤ nginx `client_max_body_size`）。

## 管理面板

`/admin` 是管理员（`server/.env` 的 `ADMIN_USERNAMES` 白名单）专用工作台，**独立于站点美术风格**（墨纸 + 朱砂印红的工具面板，样式隔离在 `client/src/styles/admin.css` 的 `.admin-app` 前缀下）。功能：站点概览（9 表计数 + 最近留言/聊天动态 + 服务器信息）、留言板审核（隐藏/恢复）、博客管理（上下线/编辑/删除/清理未引用图片）、评论删除、分享管理（删除/清理过期）、用户管理（贡献计数 + 重置密码）、聊天日志与开发日志（可追加）。所有数据服务端分页（`?page&pageSize&q`），接口统一走 `/api/admin/*`（`server/src/routes/admin.ts`，全部过管理员门禁）；账号菜单对管理员显示「管理面板」入口。


## 与原项目的差异说明

为交付**预期可用功能**与必要的安全/稳健性，做了以下处理（不改变正常可观察行为）：

- **登录修复**：原 `login.php` 用明文比对 bcrypt 哈希，登录永远失败且成功后跳转不存在的 `welcome.php`。本版用 `bcrypt.compare` 正确校验，成功后跳转首页。
- **登录人机验证（新增，应用户要求）**：登录页与注册页在口令校验/写入前增加了 ALTCHA PoW 验证（见上文「登录/注册人机验证」小节），属安全增强而非原有行为。
- **白天/黑夜模式（新增，应用户要求）**：全站主题切换（见上文「白天/黑夜模式」小节）；默认亮色为原有观感，暗色为增量能力。
- **个人主页（新增，应用户要求）**：`/u/:username` 用户主页（资料展示/编辑、头像、隐私设置、注销、内容标签），原 `/account` 账号页并入其设置标签（见上文「个人主页」小节）。
- **参数化查询**：用 mysql2 预编译语句替代原 `real_escape_string` 字符串拼接，防注入，数据一致。
- **`messages.is_displayed` 默认 1**：原插入留言不写该列，依赖列默认值才能显示。
- **配置外置**：数据库凭据、端口、WS 地址全部走 `.env`，不再硬编码。

其余所有交互细节（加载 600ms 四色块过渡、灰烬粒子、复制 tooltip、聊天 Blob 解析与 `': '` 切分、题库红绿反馈与 localStorage、留言/日志交错淡入、页脚与彩虹签名）均严格保留。
