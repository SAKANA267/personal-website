原来的加载画面是一块灰底，中间一个转圈和 "LOADING" 字样，每次换页先盖下来、停一秒再滑走。看久了想换个气质：把转圈和文字都拿掉，换成四块色块——`#5C7F71`、`#802520`、`#BA8530`、`#F5EDDC`——依次从左缘滑进来铺满，再一起从右缘滑出去。

## 四块、四色、向右扫过

四块全屏色块叠在一起，DOM 顺序就是层叠顺序，最后一块奶色 `#F5EDDC` 自然落在最上面。入场给每块一个递增的 `animation-delay`，它们就一块接一块地从左滑入；出场用同一个动画，四块齐刷刷地向右滑走。

> 进出各走一边，像一道从左向右扫过去的色块帘子。

## 关键帧，而不是 transition

最值得记的一坑：想要「左进右出」，就回不去单类 `transition` 了。

`transition` 是两个状态之间的插值，天生对称——进来走哪条边，出去就还走哪条边。最早的遮罩向下滑出，进场也就只能从下方滑上来。要进场走左边、出场走右边（两条不同的边），就得给进、出各自一段 `@keyframes`，因为关键帧自带起点和终点，不依赖上一时刻的状态：

```css
@keyframes loading-panel-in {
  from { transform: translateX(-100%); }  /* 左缘外 */
  to   { transform: translateX(0); }
}
@keyframes loading-panel-out {
  from { transform: translateX(0); }
  to   { transform: translateX(100%); }   /* 右缘外 */
}
```

再配上 `animation-fill-mode: both`，没轮到的那块就乖乖停在屏幕外左侧，等自己的拍子。

## 一个数管住节奏

整套节奏围绕一个常量 `LOADING_COVER_MS`——遮罩覆盖阶段的时长，路由守卫、首屏、外链跳转共用它，入场动画的总时长只要不超过这个数就行：

```ts
export const LOADING_COVER_MS = 600
```

想整体更快或更慢，只改这一处。四块错峰滑入，约 500 毫秒内全部铺满，停一拍，再统一向右滑出。

## 给黑白留一个例外

这站一向是黑白克制——纸色、墨色、六层灰，唯一的颜色是那行彩虹签名。加载画面是第一个破例的地方，四块色块是有意为之：它只在你换页的那一秒出现，是把「等待」本身做成了一点小小的仪式。
