打印队列里躺着一个删不掉的任务——状态在「正在删除」「错误」「正在打印」之间反复横跳，右键取消没反应，新任务也排不进队。打印机面板灯看着正常，就是不出纸；如果是共享打印机，别人的作业也跟着一起堵死。这篇笔记的主线来自[微软官方支持文档](https://support.microsoft.com/zh-cn/windows/hardware/printer/fix-print-job-stuck-in-queue-errors-in-windows)，补上一些实战里更容易踩的坑。

## 先花三十秒排除物理原因

动手清队列之前，先看打印机本身：USB 线插紧没有（可以换个口或换根线试试）、面板有没有红色错误灯、是否卡纸、硒鼓和门盖是否到位、纸盘里有没有纸。缺纸和卡纸同样会让任务停滞，这类问题清一百遍队列也没用。

## 四步主流程

### 1. 从设置里取消所有作业

开始 → 设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 选中打印机 → 打开打印队列，右键每个作业选择「取消」。多数轻度卡顿到这一步就结束了。

### 2. 重启打印后台处理程序

Print Spooler（打印后台处理程序）负责调度所有打印作业，识别类的临时毛病多半重启它就好：Win + R 输入 `services.msc`，找到「打印后台处理程序」，右键 → 重启。

### 3. 手动清空 spool 目录

取消不掉的顽固任务，缓存实体落在 spool 目录里，直接删掉：

1. 在 `services.msc` 里把「打印后台处理程序」停止；
2. 打开文件资源管理器，导航到 `C:\Windows\System32\spool\PRINTERS`，删除目录内所有文件；
3. 回到 `services.msc` 把服务重新启动。

两个细节：官方文档页面把路径写作 `...\spool\PRINTER`，实际目录名是 PRINTERS（复数）；删除文件时如果提示被占用，说明服务没停干净，回到第 1 步确认状态再删。

### 4. 重启打印机和电脑

关闭打印机 → 等待至少 60 秒 → 重新打开打印机 → 重启电脑（开始 → 电源 → 重启），然后再次尝试打印。

## 命令行三连

图形界面点得累的话，以管理员身份打开 CMD，三行命令等价于步骤 3：

```
net stop spooler
del /Q /F C:\Windows\System32\spool\PRINTERS\*
net start spooler
```

批量处理或多台机器远程协助时，用这个最快。

## 还不行的话

- 打开设备管理器，确认打印机项没有黄色感叹号；有则去厂商官网重装对应型号的驱动；
- 打印机属性 → 高级 → 勾上「直接打印到打印机」，绕过后台处理程序，复发会明显减少，代价是打印期间应用被占用式等待；
- 再跑一遍系统自带的疑难解答：设置 → 系统 → 疑难解答 → 其他疑难解答 → 「打印机」，按提示自动修复。

## 验证与收尾

重新提交一个任务或打一张测试页：能正常入队、出纸、打印机状态回到「就绪」，才算修好。清空 spool 目录时只删 PRINTERS 里的文件，不要误伤系统其他目录；操作前保存并关闭其他程序，全程使用管理员账户。多次清理仍然反复发作，就要往驱动损坏、打印机硬件或系统文件异常的方向去查——带上故障截图和状态灯情况，找单位 IT 管理员或打印机厂商技术支持（如 HP 客服）能快很多。

## 经验总结

队列卡死的本质多半是 Spooler 的缓存任务损坏，「重启服务 + 清空 spool」覆盖了大多数场景；顺序上先排除纸张、卡纸、线缆这类物理原因再动软件层，反了会白忙一场。防复发最实用的一招是「直接打印到打印机」，常年犯病的机器可以直接勾上。
