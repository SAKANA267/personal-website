把一套跑了多年的 PHP + 原生 JS 留言板搬到 Vue 3 + TypeScript，听上去是「重写」，实际约束恰好相反：肉眼可见的细节一个都不许变。提交后的提示文案、时间戳的格式、卡片淡入的先后顺序——这些是老站的气质，搬丢了就变味。

## 忠实搬运，而非重新设计

重构的第一条原则是「可观察行为不变」。用户感知到的东西，1000 毫秒的加载过渡、灰烬粒子、留言卡片的淡入节奏，全部一比一保留。

## 关键的几处搬运

最费功夫的是时间戳：原站用 `Y-m-d H:i:s`，新站照同一格式，只是从 PHP 换成 JS 的 `Date`。卡片按时间倒序，最新的在前，淡入延迟随索引递增，视线自然先落在最新一条。提交提示用复刻的 `copy tooltip`，不走浏览器原生弹窗。

### 一段最朴素的拉取

留言列表的获取，最终就是一个薄薄的 `fetch` 包装，对应原来的 PHP 接口：

```ts
async function getJson<T>(path: string): Promise<T> {
  const res = await fetch(`${BASE}${path}`)
  return res.json()
}
```

没有状态库，也刻意没上 Pinia——「store」就是几个暴露 `ref` 的普通模块。

## 没做的事

配色没动，仍是 `#fafafa` 的纸色配 `#0a0a0a` 的墨色，层次靠六层灰度；留言的 Blob 解析与 `': '` 分割也没改，那是老协议的一部分。

---

重构的终点，是让访客察觉不到重构发生过。代码变了，页面没变，任务就算完成。
